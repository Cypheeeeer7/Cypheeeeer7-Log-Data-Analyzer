# Cypher7 - Log & Data Analyzer

**Cypher7** is a lightweight, dark-themed web tool designed for real-time log parsing, error detection, and data preview.

---

## 🛠️ Installation & Setup Guide

Follow these simple steps to run **Cypher7** locally on your machine or Termux:

### 1. Clone the Repository
```bash
git clone [https://github.com/Cypheeeeer7/cypher7.git](https://github.com/Cypheeeeer7/cypher7.git)
cd cypher7
 Install Dependencies

Make sure you have Python installed, then run

pip install -r requirements.txt

Run the Application

Start the server using Flask:

python app.py

Open your browser and navigate to

[http://127.0.0.1:5000](http://127.0.0.1:5000)
